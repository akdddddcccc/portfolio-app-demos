# 学院师资与研究知识库

采集日期：2026-10-16。范围为北京师范大学未来设计学院官网「教育资源／师资介绍」目录，共52人，包含教授、副教授、副研究员、讲师、博士后、客座导师及PBL导师。目录分类不等于全员专任教师身份。

## 数据与证据

- `database.json`：供人工审查的主数据。52份简介摘要、研究关键词、官网来源和125条发表线索关联。简介采用改写摘要，不包含电话、邮箱等联系方式。
- 125条包含论文题录、待发表/审稿中稿件及1条设计作品发表记录，不是125篇已确认发表且读完的论文。
- 15条有研究内容摘要：以出版方摘要、机构存储库或作者公开研究介绍为依据；语音情绪识别条目另核对部分正文。每条记录标明核对层级、来源、限制和访问状态。
- 其余110条仅作为官网题录。已做外部检索，但不能确认的结果不进入研究结论。没列题名不代表老师没有发表论文。
- `search-review-queue.json`：未验证候选链接，可能是参考文献引用、同名作者或不可访问页面，**不进入运行时提示**。不得用候选数量当作论文核验数量。
- `profile-summaries.tsv`：简介编辑来源。所有任职及成果表述以采集日期为边界。

已记录一处题录差异：胡清清状态空间对抗图像融合论文，官网卷期页与出版方不一致，DOI对应 Mathematics 13(15), 2333。不要直接用官网错误的卷期页引用。

## 使用与维护

边缘函数直接加载生成的JS数据，按姓名和研究主题查找；只将有限数量的对应简介和论文送入上下文。新目录覆盖全部52个姓名，保留原有学生隐私边界。回答须区分官网题录与已核对的研究内容，不能补写不存在的实验结论。

```sh
python scripts/collect-faculty.py /tmp/faculty-cache
# extract-publications.py 是启发式初筛工具，使用 faculty-research-tmp 下的缓存。
# 输出须人工核对标题、作者、发表状态，再合入 database.json；不可覆盖已审查数据。
python scripts/build-faculty-database.py
python scripts/build-faculty-database.py --sqlite /tmp/yuanbai-faculty.sqlite
node --test tests/*.test.mjs
```

JSON是版本化主数据，生成的JS是线上读取格式；可选SQLite含faculty/publications两个关联表。采集的原始网页和论文只作临时核对缓存，不将全文发布到代码仓库。

验证：30项Node测试通过，包括全部52人身份命中、客座/PBL分类、题录与研究证据分级、研究主题查询和新教师进入聊天提示。模型和网络请求使用测试替身；尚未完成线上真实模型、官网检索及微信入口的端到端验收。
